# 天理中学校 入試 算数 過去問 読み取りメモ（2014〜2024年度）

- 目的：算数の対策プリント作成用。元PDFはスキャン画像（文字層なし）なので、ページ画像を目視して要約した。本文・図は転載していない。
- 読み取った資料（ユーザーが2026-10-21にアップロード。リポジトリには入れていない）：
  - 2024・2023・2022・2021・2020・2019・2018・2017・2016・2015・2014年度の入学試験問題（各年度の算数・国語・社会・理科）。
  - 英俊社「中学校別入試対策シリーズ1020 天理中学校 2025年度受験用」の別冊の解答用紙（2024〜2020年度）。解答用紙は空らんだけで、**正解は載っていない**。各大問の答えらんの数・単位・配点（推定）がわかる。
- 形式：時間40分・満点100点。計算（大問1：8問、2点ずつ）、小問集合（大問2：4〜8問、3点ずつ）のあと、大問3以降が応用問題（3〜4点の小問が2〜4つ）。大問の数は、2014・2019・2020・2021・2023年度が9、2015・2017・2018・2024年度が10、2022年度が11、2016年度が7（大問3が小問6つの集まり）。
- **大問4は、年ごとに分野が変わる**（大問の番号と分野は決まっていない。2014〜2024年度の11年分がわかった）。

## 年度別の大問（算数）

### 2018年度（10大問）
1. 計算8問。
2. 小問5（最大公約数、%でL、正方形の対称の軸の数、道のり→分、1日に進む時計の遅れ進み）。
3. リレーの走る順（通り数、条件から順番を決める）。
4. **比**（姉妹の所持金の比、出し合って残りが等しい）。
5. 仕事算（機械AとB。両方・途中で変える）。
6. 展開図から直方体（重なる点、垂直な面）。
7. 角度2つ、斜線部分の面積2つ（格子の中の三角形、円を組み合わせた図）。
8. 立体の体積2つ（円柱を半分に切った立体、直方体を組み合わせた立体）。
9. 川の上流・下流の2そうの船のグラフ（流れの速さ、静水での速さ、すれちがい）。
10. 水そうの中にブロックを置いたグラフ（毎分の量、底面積、満水の時間）。

## 算数の傾向（2019〜2024年度）
- ほぼ毎年出る：**斜線部分の面積**（円周率3.14）、**立体の体積**、**速さのグラフ**（旅人算）、**水そう・仕事算**、**図形の対称**、**規則性**、**割合・比**、**平均・データ**。大問4は、面積・体積の年が多い（2014・2015・2016・2017・2020）。
- 答えは、数・単位つきの数・記号の選択。式や考え方を書く問題はない（答えだけの解答らん）。
- 年度の新しい問題ほど、グラフや図を読み取る問題がふえている。

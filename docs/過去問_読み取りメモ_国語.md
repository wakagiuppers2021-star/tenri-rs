# 天理中学校 入試 国語 過去問 読み取りメモ（途中）

- 目的：国語の対策プリント作成用。元PDFはスキャン画像（文字層なし）なので、ページ画像を目視して要約した。本文・図は転載していない。
- 読んだ範囲（2026-10-21）：過去問PDF（2014〜2024年度、ユーザーがアップロード。リポジトリには入れていない）の**末尾にある「解答・解説」ページ**から、2024・2023・2022・2021（前半）・2020・2019・2014年度の国語を読んだ。2024年度は、問題ページも一部読んだ。**2021年度の後半、2018・2017・2016・2015年度は、まだ読んでいない**（●●）。
- 形式：時間40分・満点100点。縦書き。
- 大問の並びは年ごとに少しちがうが、**〔漢字・語句の基礎問題 3〜4つ〕→〔小説1題（10問前後）〕→〔作文〕**が基本（2014年度は、作文のあとに小説）。長文読解は、今回の対策プリントでは作らない（ユーザーの指示）。

## 気づいたこと

- 基礎問題は、**漢字（書き取り・読み・送りがな・部首・同じ漢字をふくむ熟語）**と、**語句（熟語・慣用句・ことわざ・四字熟語・対義語）**が毎年出る。文法は、独立した大問としては出にくいが、助詞の使い分け（2023）、熟語の組み立て・「の」の用法・文の構造・修辞法（比喩・擬人法・倒置法。2019・2020・2023・2024）、かなづかい・打ち消しの語（2014）の形で出る。
- 作文は、100〜200字ほど。テーマは、読書（2024）・夏休みの思い出（2023）・グラフを読み取って理由（2022）・道案内（2020）・時計の説明（2014）。体験を書く型・資料を読み取る型・説明する型がある。解答用紙の枠の形（縦書き・字数）は、まだ確かめていない（●●）。
- 過去問PDFの末尾には、解答・解説（英俊社）がある。前に「正解は載っていない」と書いたのは、別ファイルの解答用紙のこと。

# 天理中学校 入試 国語 過去問 読み取りメモ（2014〜2024年度）

- 目的：国語の対策プリント作成用。元PDFはスキャン画像（文字層なし）なので、ページ画像を目視して要約した。本文・図は転載していない。
- 読んだ範囲（2026-10-21）：過去問PDF（ユーザーがアップロード。リポジトリには入れていない）の、**問題ページ**と**末尾の解答・解説ページ**。
  - 問題ページと解答・解説の両方を読んだ年度：2015・2016・2017・2018・2019・2020・2021・2022・2023（国語の最初のページ、作文、小説の設問の一部）。2024年度は、問題ページの一部と解答・解説。
  - **2014年度は、解答・解説ページだけ**（問題ページは未確認●●）。
  - 国語は縦書きで、問題冊子は右から左にとじてあるので、PDFでは、国語の最初のページ（大問1〜）が、国語のページの**いちばん後ろ**にある。
- 形式：時間40分・満点100点。縦書き。基本は、〔基礎問題（漢字・語句・熟語・文法）3〜4つ〕→〔作文1つ〕→〔小説1題（10問前後）〕の6大問（2023・2024年度は、基礎問題4つ＋小説＋作文）。長文読解（小説）は、今回の対策プリントでは作らない（ユーザーの指示）。
- 答えかた：記号選択・ひらがなや漢字を書く・字数指定の短い記述。解答の書き方（マス目・かっこ）が、設問ごとに指定されている。

## 気づいたこと

- **大問ごとの区別（漢字／語句／文法）は、年度ごとの大問とは一致しない**。たとえば、2021年度の「部首」は大問2、2018年度の「熟語に直す」は大問3、2015年度の「文法」は大問4にある。このプロジェクトでは、国語を、漢字／語句・熟語／文法／作文の4大問（各10セット）に分けて作り、年度ごとの出題の形を、その4つに割りふった。
- 作文は、**80〜200字ほど**。形は、体験・思い出（2023）、考えと理由（2024・2021）、資料の読み取り（2022・2019・2017）、道案内（2020）、図形の説明（2018）、自己紹介（2016）、メモから記事（2015）、ものの説明（2014）。解答用紙は縦書きの原稿用紙で、100字・120字・140字・160字などの目じるしがある。段落の数・文末・使う言葉などの条件がつく。
- 漢字は、毎年、書き取り・読み・同訓異字・同音異字・部首・熟語に直す、のどれかが出る。語句は、慣用句・ことわざ・四字熟語・カタカナ語・熟語の組み立てが、毎年出る。
- **前の版のメモの訂正**：2020年度の大問1は「書き取り」ではなく「同訓異字から熟語を作る」、2023年度の大問1は「助詞の使い分け」ではなく「同じ言葉をひらがなで答える」だった。2022年度の作文は、グラフ（電力使用量）。2014年度の問題ページは、まだ読んでいない。
- 過去問PDFの末尾には、解答・解説（英俊社）がある。
